# Project Context Brief

Generated by `sdgqalab-audit` on 2026-07-22T20:59:00Z.

## Product Purpose

- The repository is the SDG AI Lab public website with a browser-based admin CMS for non-technical editors, built as an Astro static shell with client-side React islands and Supabase-backed content reads and writes.
- Evidence: `README.md`, `src/pages/admin.astro`, `src/islands/admin/AdminApp.tsx`, `src/lib/queries.ts`, `src/lib/admin-queries.ts`.

## Primary Workflows

- Public visitors browse marketing pages, projects, news, team members, partners, and page content loaded from Supabase at runtime.
- Editors sign in via Supabase magic links, complete PKCE/hash callback exchange, and manage six content types plus media uploads under `/admin`.
- Evidence: `src/pages/index.astro`, `src/lib/auth-callback.ts`, `src/islands/admin/auth/AuthCallback.tsx`, `src/islands/admin/auth/LoginPage.tsx`, `src/lib/storage.ts`.

## External Interfaces

- Public page routes are defined in `src/pages/`.
- Admin routing is hash-based inside `src/islands/admin/AdminApp.tsx`.
- External integrations are Supabase Postgres/Auth/Storage and GitHub Pages/GitHub Actions.
- Evidence: `src/pages/*.astro`, `.github/workflows/deploy.yml`, `.github/workflows/uptime-healthcheck.yml`.

## Data Contracts

- TypeScript interfaces in `src/lib/types.ts`; runtime validation in `src/lib/admin-queries.ts` before Supabase writes.
- SQL migrations in `supabase/migrations/001–004_*.sql` with RLS and editor allowlisting (`003_secure_editor_access.sql`).
- No custom REST API; browser talks directly to Supabase with anon key + RLS.
